## テストケース一覧

| No | 観点 | 前提・入力 | 期待結果 | 完了 |
|---|---|---|---|:--:|
| 1 | 正常系 | 存在する `id`（`archived=false`） | `200`、対象 `Habit` を返す | [ ] |
| 2 | 正常系 | 存在する `id`（`archived=true`） | `200`、`archived=true` の `Habit` を返す（アーカイブ後も参照可能） | [ ] |
| 3 | 異常系 | UUID形式は正しいが未登録の `id` | `404`「対象の習慣が見つかりません」 | [ ] |
| 4 | 異常系 | UUID形式でない `id`（例: `"abc"`） | `400`「id の形式が不正です」 | [ ] |
