# 画面設計（レイアウト・画面項目定義・画面イベント）

> 機能設計書の一部。**画面一覧・ルート・対応コンポーネント・画面遷移の正本**は
> `docs/baseline/functional-design.md`「画面設計」。本ファイルは各画面の**レイアウト（ワイヤーフレーム）・
> 画面項目定義・画面イベント・画面状態**の詳細のみを置く。
> - UI 表示仕様（色・状態表現）は `docs/specs/_shared/cross-cutting.md`「UI設計」を正本とする。
> - 各 API の入出力は `docs/specs/2_basic-design/api-design.md`、データ型は baseline「データモデル」を参照。
> - 入力バリデーション規則の正本は baseline「データモデル」の整合表と該当 FR に置き、本ファイルは
>   画面上の見せ方（どの項目をいつ出す/必須にする）に徹する（規則そのものを再定義しない）。

## 共通事項

### 画面共通の状態表現

| 状態 | 表示 |
|---|---|
| ローディング | [スケルトン／スピナー等] |
| エラー | [エラーメッセージ＋再試行導線。メッセージは cross-cutting.md「エラーハンドリング」に対応] |
| 空（データ0件） | [空状態メッセージ＋主要アクションへの導線] |
| 正常 | 各画面の本体 |

### 凡例（画面項目定義の列）

- **項目**: 画面上の要素名／入力フィールド名
- **種別**: 表示（read）／入力（テキスト・数値・選択・トグル・日付 等）
- **必須**: 入力項目における必須/任意（表示項目は「—」）
- **初期値／取得元**: 既定値、または表示値の取得元 API
- **入力チェック／備考**: 画面上の制約・表示条件（規則の正本は baseline / FR）
